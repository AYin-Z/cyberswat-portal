# 主站 cyberswat.cn — 设计审视报告

> 日期：2026-08-15 · 审视人：AI 协作 · 对象：展示层官网（Vue3 SPA，纯静态）
> 方法：与官网类标杆（Vercel/Stripe/GitHub）及同类战队官网（Vidar/Nu1L/0ops）对照

## 1. 现状诊断

### ✅ 做得好的（超出一般学生项目水准）

| 项 | 现状 |
|---|---|
| 设计 token 纪律 | 167 行 CSS 变量全覆盖（层级/语义色/动效/圆角/字体），全站仅 6 处硬编码色 |
| 视觉语言 | SOC 执法级深色科技风统一（终端 Hero/状态条/FIELD REPORT），品牌辨识度高 |
| 性能 | dist 仅 472K；JetBrains Mono 本地化 woff2（零外部请求）；路由级代码分割 |
| 动效 | v-reveal 滚动显现（IntersectionObserver）+ 数字滚动，克制不炫技 |
| 响应式 | 8 处媒体查询覆盖主要页面 |
| 路由基建 | per-route 标题、404 重定向、滚动行为 |

### ⚠️ 真问题（按严重度排序）

| # | 问题 | 影响 |
|---|---|---|
| 1 | **SEO 空白**：SPA 无预渲染/SSR，爬虫只能看到空壳 div#app；index.html 仅 3 个 meta，无 OG/Twitter 卡片、无 structured data | 官网在搜索引擎不可见——展示层最大的失职 |
| 2 | **移动端导航退化**：560px 以下只是缩小字号，7 个链接横排会溢出/换行难看 | 移动端访客（招新场景主力是手机）体验差 |
| 3 | **无障碍基础缺失**：无 aria 标签、无 focus 样式管理、对比度部分场景低于 4.5:1（#5f6b7d 在 #0a0e1a 上 ~4.0:1）、h1 层级不清 | 视障/键盘用户不可用；公安院校宣传有合规含义 |
| 4 | 荣誉墙/部门页交互单一（筛选已有，无搜索/排序） | 38 条荣誉 + 8 部门，信息查找弱 |
| 5 | /departments/:slug 仍是占位（已知待办，dev 子站已上线但主站未链出） | 主站→子站的转化路径缺失 |

## 2. 与标杆对照

| 维度 | 标杆做法 | 我们 | 差距 |
|---|---|---|---|
| 首屏叙事 | Vercel/Stripe：一句话 + 视觉锤 + 单一 CTA | Hero 终端叙事有记忆点，但 CTA 弱（"了解更多"散） | 中 |

## 3. 改进建议（分级）

### P0（展示层失职，尽快）
1. **SEO 基建**：接入轻量预渲染（vite-plugin-prerender 或 vite-ssg；主站仅 6 路由，成本极低）
   + 补 OG/Twitter 卡片 meta + sitemap.xml + robots.txt
   + 结构化数据（Organization/Event JSON-LD）
2. **移动端导航**：560px 以下改汉堡抽屉（或底部标签栏——官网惯例）

### P1（体验/合规）
3. **无障碍基线**：aria 标签（nav/section 语义）、focus-visible 样式、对比度修正（text-faint 提亮）
4. **主站→子站链路**：首页/部门页给 dev.cyberswat.cn 入口（"开发部协作平台"卡片），荣誉墙关联部门
5. **荣誉墙增强**：搜索 + 按年排序切换（现有筛选保留）

### P2（内容运营）
6. 首页加"最新动态"运营位（主站聚合子站脱敏数据——VISION L4 主站聚合方向的第一步）
7. /news 上线（公众号同步，已有待办）

### 明确不做
- ❌ 不引入组件库（展示站 6 页，手写 CSS + token 足够且性能最优）
- ❌ 不做 SSR 重写（预渲染即可满足 SEO，保持静态部署零运维）
- ❌ 不做暗/亮双主题（品牌深色是资产）

## 4. 与子站设计的关系

- 主站 = 展示层：**SEO + 移动端 + 无障碍** 是它的核心素养（这次审视重点）
- 子站 = 协作层：组件库 + 工作台 + token 语义化（FRONTEND.md 已定）
- **共享设计 token**：主站 #0a0e1a 系与子站 #0d1117 系同源不同值——建议统一为同一份 Primer 语义 token
  （主站 bg-canvas #0d1117 或保持 #0a0e1a，但语义名统一），品牌资产沉淀一份
- 联动：VISION L4"主站聚合子站脱敏数据"→ P2-6 是第一步

## 5. 结论

主站视觉与性能**远高于同类学生社团官网**，短板集中在"官网素养"：SEO、移动端、无障碍。
这三项都是 P0/P1 级小工程（预渲染 6 路由 + 汉堡菜单 + aria 标签），无架构风险。
建议与子站 R1 并行推进（工作量：SEO 基建 1d / 移动端 0.5d / 无障碍 0.5d）。
